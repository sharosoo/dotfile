# 한국어 교정 참고

기계가 만든 한국어 문장은 낱말이 문법에 맞아도 영어식 뼈대를 그대로 품기 쉽습니다. 단순히 “자연스럽게 쓰라”고 지시하거나 단어를 몇 개 바꾼다고 해서 번역투가 사라지지 않습니다. 문장의 중심인 서술어를 먼저 바로잡고, 명사화와 피동, 정의문, 직역어를 차례로 풀어내며 문장을 다시 짜야 합니다.

## 핵심 원칙: 서술어 중심 교정

한국어 문장은 서술어가 중심입니다. 국립국어원 『새국어생활』에서도 서술어가 문장에 필요한 성분(주어, 목적어, 보어, 필수 부사어)의 자리와 성격을 결정한다고 설명합니다. 주어와 서술어의 호응은 문법적인 격 일치뿐 아니라 실제 의미가 자연스럽게 어울리는지까지 맞아야 합니다.

문장을 고칠 때는 다음 순서를 따릅니다.

1. 문장이 전하려는 핵심 동작이나 상태를 먼저 동사나 형용사로 정합니다.
2. 그 서술어가 요구하는 주어와 목적어가 자연스럽게 이어지는지 살핍니다.
3. 길게 늘어진 절이나 나열된 명사구를 알맞은 길이로 나눕니다.
4. 문맥에 어울리는 구체적인 낱말을 고릅니다.

단어부터 바꾸기 시작하면 어색한 뼈대가 그대로 남아 글이 매끄럽게 풀리지 않습니다.

## 1. 여러 생각이 얽힌 긴 문장 나누기

한 문장에 동작이나 판단을 여럿 담으면 주술 호응이 흐려지고 명사가 줄줄이 이어지기 쉽습니다. 생각 단위로 문장을 끊으면 문장 구조가 단순해지고 전하려는 뜻이 또렷해집니다.

```
고치기 전: 시간축을 기준으로 사용자의 행동 패턴을 분석하는 것이 서비스 개선의 가능성을 도출하는 핵심입니다.
고친 뒤: 사용자의 행동이 시간에 따라 어떻게 달라지는지 먼저 살핍니다. 그 결과를 바탕으로 서비스를 어디서 고쳐야 할지 찾습니다.
```

## 2. "A는 B입니다" 형태의 정의문 풀기

원문의 서술 구조를 그대로 옮기면 명사로 끝나는 정의문이 반복되어 글이 굳어집니다. 서술어 자리에 놓인 명사를 본래 뜻에 맞는 동사나 형용사로 바꾸면 문장이 한결 자연스럽습니다.

```
고치기 전: 이 접근법의 핵심은 확장성입니다.
고친 뒤: 이 방식은 손쉽게 확장할 수 있습니다.
```

| 원문 형태 | 다듬은 표현 |
| --- | --- |
| 목표는 응답 속도의 개선입니다 | 응답 속도를 높입니다 |
| 문제는 데이터 정합성입니다 | 데이터가 서로 맞지 않습니다 |
| 핵심 요소는 사용자 편의성입니다 | 사용자가 쓰기 편해야 합니다 |

## 3. 명사화된 표현을 동사로 되살리기

동작이나 상태를 명사로 묶고 뒤에 "필요하다"나 "요구된다"를 덧붙이면 문장이 무거워집니다. 명사에 갇힌 동작을 동사로 풀어 쓰면 누가 무엇을 하는지 한눈에 보이고 문장도 훨씬 쉽게 읽힙니다.

```
고치기 전: 문제 해결을 위한 분석의 수행이 필요합니다.
고친 뒤: 문제를 해결하려면 먼저 원인을 분석해야 합니다.
```

| 의심 표현 | 다듬는 방향 |
| --- | --- |
| 개선이 필요합니다 | 개선해야 합니다 |
| 검토가 요구됩니다 | 검토해야 합니다 / 꼼꼼히 살펴야 합니다 |
| 확인이 가능합니다 | 확인할 수 있습니다 |
| 분석의 수행 / 분석을 수행하다 | 분석합니다 |
| 문제 해결의 추진 | 문제를 해결합니다 |

## 4. 불필요한 피동을 능동으로 바꾸기

기계 번역이나 초안에는 피동 표현이 자주 나타납니다. 동작 주체가 분명하다면 능동으로 바꾸고, 주어를 굳이 드러낼 필요가 없다면 주어를 생략한 능동 서술어로 쓰는 편이 깔끔합니다. 다만 도구나 시스템, 제도가 문장의 중심이거나 동작을 행하는 주체를 밝힐 이유가 없을 때는 피동이 자연스러울 수 있으므로 상황에 맞게 판단합니다.

```
고치기 전: 개선 작업이 수행됩니다.
고친 뒤: 팀이 개선 작업을 합니다. (주체가 중요하지 않을 때는: 개선합니다.)
```

| 자주 쓰이는 피동형 | 다듬은 표현 |
| --- | --- |
| 수행됩니다 / 진행됩니다 | 합니다 |
| 처리됩니다 | 처리합니다 |
| 검토됩니다 | 검토합니다 / 살펴봅니다 |
| 개선이 이루어집니다 | 개선합니다 / 나아집니다 |

## 5. 서술어와 주어·목적어의 호응 맞추기

단어의 사전적 뜻만 보고 결합하면 문법에는 맞아도 실제 쓰임새와 동떨어진 문장이 됩니다. 동사에 어울리는 주어와 목적어를 찾아 자연스러운 짝을 맞추어야 합니다.

```
고치기 전: 대응 전략을 증가합니다.
고친 뒤: 대응 전략을 강화합니다 / 대응 전략을 새로 세웁니다.
```

서술어와 문장 성분을 맞출 때는 다음 네 가지를 확인합니다.

1. 이 서술어는 어떤 주어를 필요로 하는가?
2. 이 서술어에 목적어나 필수 부사어가 필요한가?
3. 서술어와 맞물린 명사가 실제 쓰임새에서 자연스럽게 어울리는가?
4. 어색하다면 명사를 바꿀 것인가, 서술어를 바꿀 것인가?

## 6. 영어 직역어를 문맥에 맞는 표현으로 바꾸기

영어 어휘나 전치사구를 틀에 박힌 한자어로 일대일 대응하면 글의 맥락이 흐려집니다. "측면에서", "요소" 같은 말을 기계적으로 "점에서", "부분" 같은 모호한 지시어로 바꾸지 말고, 문맥에서 실제로 가리키는 대상을 밝히거나 동사로 직접 서술합니다.

| 직역투 표현 | 문맥에 맞춘 표현 |
| --- | --- |
| 시간축 | 시간 흐름, 시점, 기간, 진행 순서 |
| 맥락에서 | 이 상황에서, 이런 조건에서는, 여기서는 |
| 측면에서 (사용자 측면에서) | 사용자가 보기에, 사용자 입장에서 |
| 접근법 | 방식, 방법, 해결책 |
| 요소 | 항목, 조건, 기준 (구체적인 대상을 직접 지칭) |
| 도출하다 | 끌어내다, 찾아내다, 정리하다 |
| 활용하다 | 쓰다, 이용하다 |
| 기반으로 | 바탕으로, 토대로, 참고하여 |
| 가능성을 제시하다 | 할 수 있음을 보여 주다 |

```
고치기 전: 시간축을 기준으로 오류 발생 패턴을 분석합니다.
고친 뒤: 시간이 지나면서 오류가 언제 어떻게 일어나는지 분석합니다.
```

## 단어 치환만으로는 문장이 풀리지 않는 이유

영어 문장 구조를 그대로 둔 채 단어 몇 개만 한국어로 바꾸면 어색한 번역투가 고스란히 남습니다. 문장의 뼈대를 허물고 내용의 흐름에 맞추어 다시 써야 합니다.

```
고치기 전: 시간축을 기준으로 사용자의 행동 패턴을 분석하는 것이 서비스 개선의 가능성을 도출하는 핵심입니다.
단어만 바꾼 문장: 시간 흐름을 기준으로 사용자의 행동 패턴을 분석하는 것이 서비스 개선 가능성을 끌어내는 핵심입니다.
구조를 다시 짠 문장: 사용자의 행동이 시간에 따라 어떻게 달라지는지 먼저 살핍니다. 그 결과를 바탕으로 서비스를 어디서 개선해야 할지 찾습니다.
```

## LLM에 맡길 때 쓰는 프롬프트

```
다음 글을 한국어로 처음 작성한 문서처럼 다듬어 주세요.

규칙:
1. 한 문장에는 하나의 생각만 간결하게 담아 주세요.
2. "A는 B입니다" 같은 정의문이 반복되면 동사나 형용사 서술어로 바꾸어 문장을 풀어 주세요.
3. 명사화된 표현은 자연스러운 동사 표현으로 되살려 주세요.
4. 불필요한 피동 표현을 줄이고 능동으로 서술해 주세요.
5. 서술어와 주어·목적어가 자연스럽게 어울리는지 확인해 주세요.
6. 영어 직역 투("시간축", "측면", "맥락", "접근법", "요소", "도출", "기반")를 기계적으로 쓰지 말고 문맥에 맞는 표현으로 바꾸어 주세요.
7. 원문의 뜻과 사실 관계는 그대로 유지해 주세요.

출력:
- 교정문
- 주요 수정 이유
```

더 안정적인 교정이 필요할 때는 작업을 2단계로 나누어 진행합니다.

1. 문장마다 나타난 문제점을 먼저 짚어 냅니다 (번역투, 명사화, 불필요한 피동, 주술 불일치, 직역어).
2. 그 진단을 바탕으로 원래 뜻을 살려 자연스러운 한국어 문장으로 처음부터 다시 씁니다.

최종 출력 형식과 변경 기록(CHANGE LOG) 작성 기준은 SKILL.md의 출력 계약을 따릅니다.

## 마무리 점검 (소리 내어 읽기)

교정을 마친 뒤에는 글을 소리 내어 읽으며 다음 항목을 하나씩 확인합니다. 눈으로 볼 때는 드러나지 않던 어색한 호흡과 번역투가 입으로 소리 낼 때 분명하게 드러납니다.

- [ ] 한 문장에 한 가지 생각만 담았는가?
- [ ] "A는 B입니다" 대신 동사나 형용사로 서술했는가?
- [ ] "~의"를 연달아 쓰지 않고 말을 자연스럽게 이었는가?
- [ ] "~성", "~화", "~적", "~측면" 같은 말을 덜어내고 구체적인 표현을 썼는가?
- [ ] 불필요한 피동 표현을 능동으로 바로잡았는가?
- [ ] 서술어에 필요한 주어와 목적어를 알맞게 갖추었는가?
- [ ] 명사와 서술어가 자연스럽게 호응하는가?
- [ ] 직역투 어휘 대신 문맥에 어울리는 말을 골랐는가?
- [ ] 뻔한 주어를 덜어내고 문장을 간결하게 다듬었는가?
- [ ] 소리 내어 읽었을 때 걸림 없이 매끄럽게 읽히는가?
