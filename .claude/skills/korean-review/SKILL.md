# 한국어 문장 검토

어색하고 딱딱한 한국어 문장을 뜻은 살리면서 자연스럽게 다듬습니다. 블로그·에세이·회고, 기술 설명·제품 소개·마케팅 문구, 이메일·보고서·발표 자료, 번역문·LLM 초안에 씁니다. 표현만 바꾸는 데 그치지 않고, 문장을 한국어 어순과 자연스러운 호흡에 맞추어 다시 짭니다.

## 다듬는 순서

### 1. 원래 뜻을 먼저 확인합니다

문장을 고치기 전에 글쓴이가 무엇을 말하려는지부터 파악합니다. 원문의 의도와 맥락을 모른 채 표현부터 손대면 글의 알맹이가 왜곡되기 쉽습니다.

### 2. 번역투 표현을 찾습니다

영어 직역이나 일본어식 문어체가 섞이면 글이 건조하고 굳어집니다. 다음과 같은 상투적 표현이 불필요하게 쓰였는지 살핍니다.

- '~에 대한', '~을 통해', '~에 있어서', '~로서의'
- '존재하다', '요구된다', '이루어지다'
- '~라고 할 수 있습니다', '중요한 역할을 합니다'

이런 표현이 보인다고 무조건 걷어내지는 않습니다. 문맥상 꼭 필요하다면 자연스러운 형태로 남겨 둡니다.

### 3. 한국어 어순으로 다시 씁니다

어색한 문장은 단어 하나만 바꾼다고 풀리지 않습니다. 원래 뜻을 유지하면서 한국어에서 자연스러운 어순과 어울림으로 문장을 다시 씁니다.

```
고치기 전: 진지하고 솔직한 설명이 있었습니다.
고친 뒤: 그는 진지하고 솔직하게 설명했습니다.
```

### 4. 명사에 갇힌 뜻을 동사와 형용사로 되살립니다

영어는 명사구를 중심으로 뜻을 쌓지만, 한국어는 움직임이나 상태를 동사와 형용사로 바로 서술할 때 자연스럽습니다. 영어 명사마다 한국어 명사를 일대일로 짝짓지 않고, 그 말이 가리키는 동작을 풀어 '누가 무엇을 했는지', '무엇이 어떻게 달라졌는지'를 서술어로 씁니다.

```
고치기 전: 사용자 이탈 원인에 대한 분석을 진행했습니다.
고친 뒤: 사용자가 왜 떠나는지 분석했습니다.

고치기 전: 영화는 한국 전통의 아름다운 재현이었다.
고친 뒤: 영화는 한국의 전통을 아름답게 재현했다.

고치기 전: 프로젝트의 진행 상황에 대한 보고서 작성이 요구됩니다.
고친 뒤: 프로젝트 진행 상황을 보고서로 정리해 주세요.
```

다만 전문 학술 용어나 제도 명칭처럼 명사 자체가 문장의 초점이거나 고유 개념일 때는 억지로 동사로 바꾸지 않습니다.

### 5. 내용과 무관한 억지 틀을 걷어냅니다

기계가 작성한 글은 짜임새 있어 보이게 하려고 불필요한 분류나 대칭 구조를 자주 만듭니다. 원문에 없는 틀을 억지로 덧씌우지 않습니다.

- 셋으로 묶을 이유가 없는데 '세 가지 축', '세 가지 핵심 요소', '세 가지 관점'으로 틀을 짜지 않습니다.
- '축', '기둥', '레이어', '차원', '측면'이 실제 구조적 관계를 설명하지 않는다면 구체적인 내용을 바로 서술합니다.
- '단순히 X가 아니라 Y', 'X를 넘어 Y', '도전과 기회' 같은 상투적 대구를 기계적으로 만들지 않습니다.
- '핵심은', '정리하면', '결론적으로'를 앞세워 바로 앞에서 한 말을 되풀이하지 않습니다.
- 근거 없이 '중요한 전환점', '핵심 역할', '의미 있는 시사점', '새 지평'처럼 뜻을 부풀리지 않습니다.
- 소제목이나 글머리표 길이를 기계적으로 맞추지 않습니다.

```
고치기 전: 이 제품은 속도, 정확성, 안정성이라는 세 가지 축에서 평가할 수 있습니다.
고친 뒤: 이 제품을 평가할 때는 속도와 정확성, 안정성을 따져야 합니다.

고치기 전: 이 문제는 비용, 속도, 신뢰라는 세 가지 핵심 축을 중심으로 이해해야 합니다.
고친 뒤: 이 문제를 이해하려면 비용이 얼마나 드는지, 얼마나 빠른지, 믿을 만한지를 살펴봐야 합니다.
```

실제 분석 모형, 좌표축, 조직의 공식 전략처럼 '축'이나 '차원'이 실제 관계를 가리킬 때는 그대로 씁니다. 내용상 항목이 실제로 셋이고 목록 형태가 전달에 도움이 될 때도 셋이라는 이유만으로 풀어 쓰지는 않습니다.

### 6. 주어와 서술어의 호응을 맞춥니다

문장이 길어지면 주어와 서술어가 어긋나기 쉽습니다. 특히 '~하는 것', '~다는 점'으로 시작하는 문장은 끝까지 읽어 보고 서술어와 자연스럽게 이어지는지 살핍니다.

```
고치기 전: 그가 진지하게 말한 것은 그 자리에서는 누구도 반박할 수 없었습니다.
고친 뒤: 그는 진지하게 말했고, 그 자리에서는 누구도 반박할 수 없었습니다.
```

### 7. 지시어를 구체적인 대상이나 말로 바꿉니다

'그 일', '이 점', '이 부분'처럼 가리키는 대상이 흐릿한 지시어가 이어지면 독자가 앞뒤 맥락을 헤아리기 어렵습니다. 가리키는 대상을 분명히 밝혀 씁니다.

```
고치기 전: 어제 그 일을 처리하지 못했습니다. 이 점 때문에 오늘 일정이 늦어지고 있습니다.
고친 뒤: 어제 보고서 마감을 못 했습니다. 그래서 오늘 발표 준비가 늦어지고 있습니다.
```

### 8. 군더더기 문장을 뺍니다

앞선 문장의 뜻을 그대로 되풀이하거나 글의 핵심과 무관한 문장은 덜어냅니다. 문단마다 새로운 사실, 근거, 판단 가운데 하나도 담겨 있지 않다면 줄이거나 없앱니다. 할 말이 끝났는데 억지로 새 문장을 덧붙여 마무리하지 않습니다.

```
고치기 전: 오늘은 보고서를 한 줄도 못 썼습니다. 아무것도 쓰지 못했다는 뜻입니다.
고친 뒤: 오늘은 보고서를 한 줄도 못 썼습니다.
```

### 9. 소리 내어 읽으며 리듬을 살핍니다

눈으로 읽을 때는 자연스러워 보여도 입으로 소리 내어 읽으면 숨이 차거나 어색한 곳이 드러납니다. 소리 내어 읽다가 턱턱 걸리는 문장은 아직 덜 다듬어진 문장입니다.

## 자주 고치는 표현

| 어색한 표현 | 자연스러운 방향 |
| --- | --- |
| ~에 대한 질문 | ~을 묻는 질문 |
| ~을 통해 | ~로, ~하면서, ~해서, ~덕분에 |
| ~에 있어서 | ~에서, ~할 때, 삭제 |
| ~로서의 | ~인, ~로 사는, ~의 |
| 존재하다 | 있다 |
| 위치하다 | 있다 |
| 가지고 있다 | 있다, 지녔다, 믿는다, 느낀다 |
| 요구된다 | 해야 한다, 필요하다 |
| 이루어지다 | 하다, 생기다, 벌어지다 |
| 설명이 있었다 | 설명했다 |
| 중요한 역할을 한다 | 중요하다, 도움이 된다 |
| 영향을 미친다 | 바꾼다, 흔든다, 영향을 준다 |
| 하나의 방식입니다 | 한 방법입니다, 그렇게 볼 수 있습니다 |
| 세 가지 축, 핵심 축 | 항목을 바로 나열하거나 서로 어떤 관계인지 구체적으로 설명 |
| 관점에서, 측면에서, 차원에서 | 무엇을 어떻게 보는지 동사로 직접 서술 |
| 단순히 X가 아니라 Y | 실제 대조가 없으면 X 또는 Y를 바로 서술 |
| X를 넘어 Y | 실제 범위가 넓어진 것이 아니면 Y를 바로 서술 |
| 도전과 기회 | 구체적인 문제와 가능한 일을 각각 서술 |
| 중요한 전환점, 의미 있는 시사점 | 무엇이 어떻게 바뀌거나 무엇을 알 수 있는지 서술 |

## 주의할 점

- 문장을 매끄럽게 고치더라도 글쓴이가 전하려는 사실과 의도를 왜곡하거나 빠뜨리지 않습니다.
- 쉬운 말이 항상 최선은 아닙니다. 문맥에 정확히 부합하는 전문 용어와 한자어는 그대로 남깁니다.
- 도구, 시스템, 제도가 중심인 문장에서는 피동형이 자연스럽습니다. 다만 사람이나 동작 주체가 분명할 때는 능동형으로 바꾸는 편이 낫습니다.
- '축', '관점', '측면', '차원' 같은 말도 문맥에 맞으면 자연스럽습니다. 낱말 하나만 보고 기계적으로 지우지 말고, 그 말이 실제 관계를 설명하는지 살핍니다. AI 문체의 흔적은 오류 판정표가 아니므로, 셋을 나열하거나 대구를 썼다는 이유만으로 고치지 않고 상투적인 틀이 뜻보다 앞설 때만 걷어냅니다.
- 문장을 평범하게 만들려고 글의 개성과 어조를 지우면 안 됩니다. 글의 목적과 독자에 어울리는 말투를 유지합니다.

동작 주체가 분명한 문장은 능동형으로 바꿉니다.

```
고치기 전: 이 제품은 많은 사람들에게 사랑받고 있습니다.
고친 뒤: 많은 사람이 이 제품을 좋아합니다.
```

## 마지막 점검

- [ ] 글쓴이가 말하려던 원래 뜻이 온전히 유지되었는가?
- [ ] 주어와 서술어가 문법과 의미 모두 자연스럽게 호응하는가?
- [ ] 지시어가 가리키는 대상이 분명하게 드러나는가?
- [ ] 명사에 갇힌 동작과 상태를 동사와 형용사로 되살렸는가?
- [ ] 내용과 무관한 억지 틀(세 가지 축, 상투적 대구)을 걷어내고 알맹이를 직접 서술했는가?
- [ ] 근거 없는 중요성 부풀림이나 의미 없는 요약 문장을 뺐는가?
- [ ] 각 문단이 새로운 사실, 근거, 판단 가운데 하나 이상을 전하는가?
- [ ] 소리 내어 읽었을 때 걸림 없이 매끄럽게 읽히는가?
