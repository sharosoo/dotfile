# 엔카/헤이딜러 API 파이프라인 (2026-09 실측)

## 엔카 검색 API (서버 직접 호출 가능)

```
GET https://api.encar.com/search/car/list/general?count=true&q={q}&sr={sort}
```

- q 문법: `(And.Hidden.N._.CarType.A._.Manufacturer.현대._.ModelGroup.아반떼._.Options.{token}.)` — 구분자 `_.`, 값은 한글 가능.
- 한글이 들어간 q는 **전체를** `urllib.parse.quote(q, safe='()_.')`로 인코딩한다 — 원문 한글을 URL에 붙이면 `UnicodeEncodeError`(ascii codec)로 실패한다. `safe`에서 `.`을 빼면 필터 구분자 `_.`가 깨진다. curl로 조립할 때 `|`·`$` 미인코딩 시 400.
- sr 예: `|PriceAsc|0|300` (파이프는 %7C로 인코딩). 유효 정렬: ModifiedDate, MobileModifiedDate, PriceAsc, Mileage, Year. `Price`는 400.
- **404 = 존재하지 않는 필터 키, 400 = 문법 오류** (키 탐색에 이용).
- 토큰 미상 옵션은 모바일 UI에서 캡처: `m.encar.com/ca/search.do#!...` → 필터 > 옵션 > 카테고리 탭 > 항목 체크 > 확인 → 해시의 `Options.{token}` 그대로 사용.
- **ACC 전용 토큰: `Options.크루즈 컨트롤(어댑티브)`** — `일반`과 상호배타(그랜저 ID 교차검증). 오토 크루즈(일반 CC) 차를 걸러내려면 `(일반)`.
- 검색 결과 아이템에는 옵션 목록이 없다. 크루즈 종류 판정은 (1) ACC 토큰 포함 여부 + (2) 상세페이지 문구로 이중 확인.

## 엔카 상세 API (리스크 플래그 자동화)

- `GET /v1/readside/inspection/vehicle/{id}` → 성능기록부: `master.accdient`(골격사고), `simpleRepair`, `detail.usageChangeTypes`(렌트 등 용도이력), `seriousTypes`(전손/침수/도난), `boardStateType`(외판등급), `tuning`, `mileage`(기록부 주행거리 — 매물 주행거리와 3만km+ 불일치 시 경고).
- `GET /v1/readside/vehicle/{id}` → 매물 메타: `spec.seatCount`(2=2인승 화물밴), `spec.fuelName`·`mileage`·`displacement`, `category.originPrice`(신차 기준가, 만원 — 잔존율의 분모), `category.gradeName`, `contact.userType`(DEALER/CLIENT/REPEAT), `manage.viewCount`·`reRegistered`. 리스트 아이템에 없는 필드라 저가 띠 해석 전에 먼저 붙인다.
- `GET /v1/readside/vehicles/car/{id}/options/choice` → 옵션+원가. 단 **크루즈 항목은 비어 있음**.
- `GET /v1/readside/record/vehicle/{id}/open?vehicleNo={번호판}` → 성능기록부 원문.
- `GET /v1/readside/diagnosis/vehicle/{id}` → 엔카진단 항목별 결과. 이상 항목(REPLACEMENT 등)을 목록으로 뽑고 `CHECKER_COMMENT`·`OUTER_PANEL_COMMENT`를 반드시 읽는다 — 구조 플래그(`accdient=False`)가 무사고여도 코멘트에 쿼터·용접 같은 골격 키워드가 언급되면 사고차로 취급한다. 진단 미등록 매물은 상세페이지 정보로 보완한다.
- `GET /v1/readside/diagnosis/vehicle/{id}/sellingpoint` → 판매자 강조 문구 + AI 추천 문장.
- 보험이력 금액은 유료 조회 없이 상세페이지 innerText에서 읽힌다: `차량이력 → 내차 피해 → 총 X원 (N회) / 타차 가해 → 총 Y원 (M회)` — 후보 스크리닝 1차 필터로 쓴다.
- **장기렌트·리스 승계 매물은 후보에서 제외한다** — 리스트 API의 `SellType`이 `렌트`/`리스`면 승계매물이다(인수 조건·보증·잔존 리스크가 매매와 달라 가격 비교 대상이 아니다). 최신 연식+초저주행(수 km)+극저가 조합도 승계매물의 전형 패턴이다.
- 검색 → 상세 일괄 수집 → SQLite(listings 테이블: price/year/mileage/accident/usage/risk_flags/cost_month) → `ORDER BY cost_month, price` 1차 랭킹. 사고+렌트 출신이 저가 매물의 주성분이라, 리스크 0 필터를 먼저 걸고 밴드 최저가를 고른다. 1차 랭킹은 방향 잡기용 — 상위 5~7개는 판매자 문구·보험이력 금액·진단 코멘트로 재랭킹하면 순위가 뒤집히는 게 일상이고, 동일 차량 재등록(ID만 다른 쌍)은 하나로 묶어 판단한다.
- 저가 띠 탐색은 `sr=|PriceAsc|{offset}|200`으로 offset 0/200/400 누적으로 뽑는다 — 가격 오름 정렬은 200건이 전부 최저가 띠라 원하는 밴드가 안 잡힌다.
- 연 자동차세(승용 비영업): cc당 200원 단일율(1,598cc≈1,618cc, 연 차이 4,000원) — 배기량 구간 프리미엄 얘기는 구닥다리 정보.
- SM6 참고(2026-09 실측): 2016~19 2.0 밴드 min 350/med 450/max 499 — y8~10에 감가 끝난 띠. 5년 감가율 55~60%(중형 평균보다 빠름)지만 노후 구간에선 절대 감가액 작음. 정비 리스크: 서모스탯 20~30만·워터펌프 30~50만·에어컨 20~40만 고질병, 1.6 TCe/2.0 GDe는 게트락 7DCT(오일+클러치 학습값 초기화 필수), LPe는 엑스트로닉 CVT(렌터카 출신 다수). 렌터카·장애인용 배지는 가격 밴드에 섞여 있으니 별도 분류.

- QM6 2.0 LPe 실측(2026-09): 2023+ LPG 91건 중 5인승 74 / 2인승 밴 17. '퀘스트 …LE' 배지 = 2인승 화물밴이라 1,230~1,790만 저가 띠를 형성한다(신차 기준가 2,810만). 5인승 중위 2023 LE 1,840·RE 1,960 / 2024 RE 2,250 / 2026식 신차급 2,780, 신차 기준가 LE 2,749~2,931·RE 3,095~3,220 → 3.5년차 잔존 58~72%. 용도이력은 렌트 11·영업용 4건, 성능기록부 사고 True 3건. LPe 대표 정비 사례는 연료펌프·LPG 압력센서(16만km+ 부조·시동 꺼짐), 점검 항목은 냉간 시동·가스 냄새·연료게이지 오차(도넛 탱크라 트렁크 손실 없음). ACC(어댑티브)는 LPG 670건 중 161건이고 배지별로 RE 시그니처 77 · RE 39 · 프리미에르 33 · LE 시그니처 10 · LE 2 — **2.0 LPe LE 기본형에는 ACC가 없다**. ACC가 하드 조건이면 LE 저가 후보를 1순위에 두지 말고 RE/프리미에르 밴드에서 보험 이력 클린을 찾는다. 10년 보유에서는 저가 고km(9.3만km·1,720만)가 3.4만km(2,420만) 대비 정비 누적에서 역전한다.

## 전 차급 스캔 요약 (2026-09, 10년내 국산 36개월 TCO 관점)

- ACC(크루즈 컨트롤(어댑티브)) 최저가 띠: 올뉴K3 664~730 / CN7 850 / 쏘나타 LF 589 / 그랜저 560 / 니로 700(단 20~26만km 노후) / 모닝 JA 1,080 / 레이 FL 1,230~1,320 / 캐스퍼 870(1.0T 터보 980~1,000) / 스팅어 890 / 카니발 590.
- BSD-only(후측방 경보 시스템) 최저 띠: 모닝 JA 380~480(12~14만km) / K3 440~620 / 아반떼 AD 490~600 / 그랜저 360~600 / 카니발 530 / 쏘나타 470.
- 경차 출력 예외: 모닝·레이는 자연흡기 1.0L(76마력)로 터보 없음 → 출력 부족. 캐스퍼만 1.0T 터보(100마력) 존재 — 경차 예외는 '터보만' 적용. 캐스퍼 1.0T 실측(2026-09): 터보 매물 9대뿐, 980~1,000만(2022~24식). 990(4만km)·980(11만km)은 내차피해 2회/316만·6회/879만으로 탈락, 유일 후보 1,000만(15.1만km, 진단 무사고, 내차피해 1회/58만) — 단 소유자변경 3회(2026-07 두 달 내)로 매도 회전 의심, 판매자 사유 확인 필수.
- 니로 HEV: ACC 장착이 많지만 저가 밴드는 20만km+ 노후가 대부분(하이브리드 배터리 남은 수명 리스크) — 저km 후보는 1,100+로 급등. 차세대 감가와 배터리 SOH 확인이 전제.
- TCO 지배 구조(재확인): 차급 내려갈수록 감가 절대액은 커져도 보험·세·유류·정비가 작아져 36개월 총액은 역전된다. ACC 유무는 월 2~6만 차이로, 'ACC를 월 3만에 사겠다'는 별도 의사결정으로 분리해 판단한다.
- 60개월 프레임에서는 역전이 더 강해진다 — 감가 비중이 줄고 보험·정비·유류 누적이 지배. 36개월 1위(K3 620·BSD 준중형 40.7)가 60개월에선 경차·소형보다 뒤로 밀린다. HEV 노후차(니로 26만km)는 배터리 보증 종료로 기대비용 +0.9만/월 보정 필요. 출력 예외 터보 경차(캐스퍼 1.0T)는 60개월에서도 NA 경차 대비 +2.1만/월 — '출력+ACC 프리미엄'으로 정의하고 선택은 사용자 몫.
- 전 모델 스캔 → 상위 20 TCO 랭킹 워크플로: (1) 전 모델그룹 × ACC/BSD 토큰 × PriceAsc 100건씩 풀 수집(429 레이트리밋 → sleep 0.3~2s) (2) 중복 제거(모델+연식+km+가격 키) (3) 그룹별 ACC 우선 최저 대표 추출 (4) TCO 계산 → 리스크 사유 제외(44만km, 택시형, 카고, 특수변형, 1세대 EV 배터리 미보증) (5) 검증 완료 매물 우선 반영. 1세대 EV(아이오닉 2016)는 연료비 4만/월로 TCO 1위가 나오는데 배터리 SOH 미보증이라 추천 시 경고 필수.
- **record/open 무료 판독은 VIN으로도 가능**: `/v1/readside/record/vehicle/{id}/open?vin={VIN}` — 번호판 없이 성능기록부 API의 `detail.vin`으로 이어서 카히스토리급 데이터(`myAccidentCnt`/`myAccidentCost`, `otherAccidentCnt`/`otherAccidentCost`, `ownerChangeCnt`, `totalLossCnt`, `floodTotalLossCnt`, `accidents[]` 일자·보험금·부품/공임/도장)를 무료로 읽는다. insp 404 매물은 이 경로 자체가 없으므로 상세페이지 '차량이력' 섹션으로 fallback.
  - **재등록 쌍에서는 형제 ID로 vin을 찾는다**: 같은 차가 ID만 다르게 2건 올라오면 한쪽만 insp 200이고 다른 쪽은 404인 경우가 흔하다(매물·가격·연식·km·배지 동일). 404를 '데이터 없음'으로 결론내지 말고 형제 ID 전부에 insp를 시도해 vin을 확보하고, vin이 나온 ID로 record/open을 부른다.
  - **insp의 `accdient=False`(무사고) ≠ 보험 이력 없음**: 그 플래그는 골격 사고만 본다. 무사고 표기인데 record가 내차피해 4건/588만 + 타차가해 4건/570만(하루 3건 집중일 포함)인 매물이 실제로 나온다 — 후보 확정 전 record/open을 항상 따로 읽고, 아니면 1순위가 뒤집힌다.
  - `accidents[]`의 `type`은 피해 유형 구분(1=내차 피해, 2=단순, 3=타차 관련) — 보험금보다 부품+공임+도장 합계가 실제 규모 지표다.
- 아이오닉 '2016' = 엘란트라 GT 기반 HEV(EV 아님 — '아이오닉 일렉트릭'은 별도 모델). search 아이템에 `FuelType`이 있으므로(값 예: `LPG(일반인 구입)`) 연료 구분은 필터로 처리하고, 연료·모델명이 애매하면 `Model` 값으로 가른다. HEV 26만km+는 배터리 보정 +0.9만/월 필수.

## 주행거리 구간별 정비비 모델 (60개월·연1.5만km 기준, 준중형 실측단가)

- 10만km → 17.5만km: 약 588만/5년(9.8만/월) — 타이어·미션오일·미션마운트·라디에이터·허브베어링·등속조인트 도달.
- 15만km → 22.5만km: 약 635만/5년(10.6만/월) — 타이어 2회·플러그·볼조인트/부싱·쇼바·워터펌프 추가. 10만km보다 47만 더 든다.
- 20만km → 27.5만km: 약 570만/5년(9.5만/월) — 패드·연료필터 등 소모품만 남고 대형 부품은 이미 교환된 차가 많아 오히려 낮게 나올 수 있으나, 20만km+는 미션·엔진 하부 리스크가 비용표 밖에 존재(확률적 총액).
- HEV(아이오닉/니로) 20만km+: 배터리 냉각팬·인버터 쿨런트·12V 소배터리 추가 +43만/5년, 셀 고장 기대비용 450만×8% = +0.6만/월 별도.
- 정비비를 km 구간별 실측치로 넣으면 순위가 재편된다: 정비 9.8~14.1만/월은 감가(2.5~8.4)보다 큰 항목 — '차값 싼 노후차'가 정비비에서 역전당하는 구조.
- 디젤은 연료필터(4만km)·DPF/EGR/인젝터(12만km) 항목이 추가되어 가솔린보다 정비비 +10~15%. LPG는 인젝터 리스크 대신 연료비 30% 절감.
- 사용자 배제 룰(2026-09 확정): EV·하이브리드(고연차 정비비)·경차(레그룸) 전면 제외. 외판·트렁크·도어 교환/판금은 괜찮음 — '엔진만 튼튼하면 됨'이 1순위 판정 기준. 엔진 상태 특진단: diagnosis API의 비정상 항목 중 ENGINE/CYLINDER/RADIATOR/WATER_PUMP/TURBO/OIL/INJECTOR/TIMING/MOUNT 키워드 매칭 + CHECKER_COMMENT·OUTER_PANEL_COMMENT 골격 키워드 검사. 진단 미등록 매물은 상세페이지 성능기록부 섹션(교환/판금/부식 카운트)으로 대체 판독.
- 인기모델 저가 띠의 이력 현실: 아반떼 AD 밸류플러스 490~650 밴드 15건 판독에서 내차피해 클린(≤250)은 2건뿐 — 인기모델 최저가 매물은 사고 이력 위에 가격이 형성된 케이스가 지배적이다. 렌트 출신 표기(usageChangeTypes)가 있어도 엔진·골격 진단이 정상이면 감가 반영 가격에서 유효 후보. '최저가 1대'만 보지 말고 같은 밴드에서 이력 판독으로 살아남은 매물을 찾는 절차가 필수.

## 보증기간의 TCO 정확한 취급 (제조사 보증표)

- 보증은 **제조결함(고장)만** 덮는다. 소모품(타이어·브레이크 패드·엔진오일·LPG 연료필터·냉각수·배터리)은 보증 구간 안에서도 전액 유상이다 — 10년 정비 총액에서 소모품이 85~95%를 차지하고 고장 기대값은 10년 100만 내외다. 정비비 항목을 보증으로 0 처리하면 총액이 크게 틀어진다.
- 항목별 기간이 다르다(제조사·모델별로 공식 보증표를 확인): 차체·일반부품 3년/6만km, 엔진·동력전달 주요부품 5년/10만km, ECU·촉매·필터 7년/12만km, 그 외 부품 5년/8만km, 배터리 2년/4만km (르노코리아 승용 실측값). 소유주가 바뀌어도 잔여 기간은 승계되는 경우가 많다.
- 장기 보유에서는 커버 구간이 앞부분에만 걸리고, 그 구간은 km가 낮아 고장 위험이 가장 낮다. 10년 보유에서 보증이 면제해주는 금액은 월 0.3만 수준 — 후보 간 보증 잔여 차이는 순위를 바꾸지 못한다. 보증 잔여는 '할인'이 아니라 '리스크 회피'로 값을 매긴다.
- 연차별 정비 곡선(연 1.5만km, km구간 단가 기준): 보증 초반 60~65만/년 → **보증 종료 직후 140만/년으로 점프** → 20만km+ 200만/년. 보증 만료 시점이 정비비 변곡점이라 연차별 표에 보증 경계를 함께 표시한다.

## 120개월(10년) TCO — 감가 축소, 정비·연료 지배

- 감가 추정: 4~7년차 실측 중위가에서 지수 연장하고 고km 페널티(만km당 −25만 내외)를 적용한 뒤, 같은 세대 10년차 실측(중위 km)으로 교차검증한다. 잔존 ±100만 = 120개월에서 월 ±0.8만이라 순위는 흔들리지 않는다.
- 항목 구조가 바뀐다: 10년에서 감가 12~18만 < 정비 8~15만 < 연료 16.5만. 연료비가 감가와 맞먹고, 정비가 매입가 차액을 상환한다.
- **진입가 vs 정비 역전**: 매입 −700만(9.3만km 시작, 1,720만) vs +700만(3.4만km 시작, 2,420만)을 비교하면 10년 정비·고장 차액이 +680만이라 월합에서 저가 고km가 뒤진다. 감가만 보면 저가가 이기지만 총액은 지거나 비긴다 — **매입가 차액과 정비 누적 차액을 같은 표에 놓는 절차가 필수**다.
- 옵션 패키지(ACC+상위 트림) 값은 보유기간의 함수다: 3년 보유면 감가로 증발, 10년이면 월 2.4~3.2만(= 10년 290~380만)으로 ACC+풍풍시트+매직테일게이트+360뷰를 사는 셈. 트림 추천 전에 보유기간을 먼저 확정한다.
- 3년/5년/10년 월합계를 한 표에 병기한다: 실측 후보에서 3년 78~85만 → 5년 64~67만 → 10년 56만. 기간을 늘리면 감가 프리미엄이 희석되고 등급 간 순위가 재편된다.

## 정비이력(10만km+) 확인 경로 — 데이터 접근성 경계

- 엔카 API에는 정비이력 엔드포인트가 없다(vehicles/car/{id}/maintenance 등 전부 404) — 보험이력(사고)과 성능기록부(단발 점검)만 가능.
- **정비이력의 공식 출처는 자동차365(car365.go.kr) 통합이력조회**: 정비소가 자동차관리법에 따라 의무 전송한 정비 내역(부품·공임·일자·주행거리). 단, **본인차량 또는 소유자 동의** 필수 — 구매자가 임의로 타인 차량의 상세 정비이력을 못 본다. 미동의 시 '정비이력 횟수'만 공개.
- 실전 우회: (1) 매매업자 매물이면 **매매용차량 조회**로 업자 명의 차 통합이력 확인 가능 (2) 판매자에게 '자동차365 통합이력 조회본' 캡처 요구 — 정비 루틴 있는 차주는 거부 안 함 (3) 정비이력 횟수 + 주행거리 변화 그래프(연간 주행 패턴)로 정비 주기 역산 (4) 최종은 카바조 리프트에서 오일누유·미션오일 상태로 '관리된 차'인지 물증 확인.
- 고Km 매물 판정 기준: 정비이력 횟수가 연 1~2회 이상 + 주행거리 그래프가 연속이면 관리된 차. 횟수 0~1회이면 자비수리 또는 방치 — 성능기록부가 무사고여도 위험군.

## 신차 vs 중고 TCO 비교 규칙 (2026-09 검증)

- 비교 시 전제를 통일해야 한다: (1) 보험 — 신차 5y 1,050/중고 850~950(초보 첫차 기준, 유저표의 550은 경력자 요율) (2) 연료 — 연 1만km 통일(유저표 300만은 연 4천km 수준) (3) 신차 잔존율 55~60%(유저표 60.5%는 상한) (4) 할부이자는 현금구매면 0.
- 실측 결론(초보 첫차·연 1만km·60개월): 중고 2,476~2,626 vs 신차 3,293~3,643 — **중고 우위 680~950만**. 보험·감가 시나리오를 최악으로 밀어도 격차 370만 이상 유지.
- 신차 우위가 되는 조건: ① 중고 매물이 사고차로 판명(감가+정비 +450) ② 보유기간 10년+에서 신차 무상보증 5년+연장 활용 ③ 연간 4천km 이하 극소주행. 이 조건이 아니면 '신차가 나아 보이는 TCO'는 보험·연료 전제 오류에서 나온다.
- 신차의 진짜 메리트는 TCO가 아니라: 5년 무상보증(정비 리스크 0)·최신 ADAS·하자 보증 — 리스크 회피 비용으로 환산하면 월 10~13만.

## 헤이딜러 (API 없음, DOM 수집)

- 목록: `https://www.heydealer.com/market/cars?brand={slug}&model-group={slug}` — 첫 화면 10대만 렌더(page 파라미터로 다음). 슬러그: 현대=xoKegB, 기아=2oV0gK, 아반떼=XyQ1gy, 쏘나타=Ne8v1M, K3=VMjJGM, K5=EMpDLM.
- 카드 = `a[href*="/market/cars/"]` innerText. 파싱: `r'(\d{4})년 \((\d{2})/(\d{2})\)'` 연식, `ㆍ([\d.]+)만km`, `보험 (\d+)건 ∙ (\d+)만원`, 완전무사고/무사고 구분, 두 번째 가격이 판매가.
- __NEXT_DATA__ 없음(RSC 스트림), api.heydealer.com 추측 호출은 404/406.
- 구매 매물 성격: 선별 무사고 + 1년 무료보증 + 단순변심 무료환불 + 전국 배송. 대가로 엔카 대비 +10~70% 프리미엄 (올뉴K3 프레스티지 2019: 엔카 730~790 vs 헤이딜러 1,230~1,290 실측).
- 헤이딜러 제로(매도 경매)는 진단 누락→보상 분쟁·공정위 신고(2026-08) 사례가 있다. 매수자 관점에서도 eye 인증이 있어도 카바조 병행.

## 보험이력(카히스토리) 판독 기준

- **내차피해 1회 ≤200 OK**(범퍼급 120~160), 1회 400+ 또는 2회 이상 → 협상/거름. 골격(쿼터·루프·사이드실패널) 관련이면 거름.
- 타차가해 1,000+ → 내차도 큰 사고 간접 추정. **전손·침수·도난 = 무조건 거름**.
- **주행거리 컷 금지** — 15만 km 자체가 리스크가 아니라 '관리 증거 × 가격 격차'로 판단. 15만 km 이후 리스크는 엔진보다 미션·냉각·누유·하체 부싱·보조부품이고, 질문은 "향후 3만 km당 수리비". 15만 km가 10만 km 대비 50만 미만 싸면 10만 km, 200만+ 싸면 관리 증거 확인 후 15만 km도 후보.
- **저주행 프리미엄 함정**: 8만 km가 동형 15만 km 대비 +70만이면 그 차액은 사고 이력 위에 얹힌 프리미엄일 수 있음 (실측: 올뉴K3 2019 8만km 690만 = 내차피해 2회/334만 + 2025-10 수리 375만 직후 매물화 → 탈락). 엔카 `record/open` API에 번호판만 있으면 myAccidentCnt/Cost·accidents[](일자·부품/공임/도장)를 무료로 읽을 수 있다 — 유료 카히스토리 조회 전 1차 판독용.
- 미표시 공백의 의미: 자차담보 미가입 기간, 운수공제(렌트/택시) 처리, 자비수리 — 이력이 깨끗해도 공백을 반길로 읽지 않는다.
- 소유자 변경 주기가 짧으면(구매 후 몇 개월 재매도) 문제차 가능성. `미확정`은 보험사→개발원 2.5~3개월 반영 지연.
- 수리비(부품/공임/도장)가 보험금보다 정확한 규모 지표.

## 성능·상태점검기록부 판독 기준

- **주요골격 X(교환)/W(판금·용접) = 사고차**(프론트패널·크로스멤버·사이드멤버·휠하우스·필러·쿼터·루프·사이드실패널·플로어·트렁크플로어·리어패널). 후드·펜더·도어·트렁크리드·범퍼는 외판/소모품 — X/W여도 '사고' 아님(단순수리, 감가 소, 협상 카드).
- 발급일 120일 이내만 유효. 잘리면 제외. 주행거리가 자동차관리정보시스템보다 적으면 특기사항에 기재 의무(주행거리 조작 체크).
- 용도이력: 렌트 출신은 감가 반영 가격이면 OK, 택시(개인제외)·경비부활 배제.
