# Used Car Purchase Consulting (Korea)

## Overview

한국 중고차 구매 상담: 플랫폼 신뢰도, 예산·보유기간별 차종 추천, 감가 포함 월비용 모델링, 트림/옵션 판정, 매물 검증. 근거는 DCInside 중고차 갤러리의 실제 글·댓글과 실매물 시세 데이터로 확보하고, 추정치는 '추정'으로 표기한다.

## Always-on Rules

- 답은 짧고 결론 먼저(1순위 + 이유). 계산이 들어가면 반드시 execute_code로 계산표를 만들어 보여준다 — 뇌 계산 금지.
- 사용자가 방향을 제시하면("X가 맞을 거 같다") 반박용 허수아비를 세우지 말고 그 방향을 숫자로 검증한다.
- 질문 범위 밖 정보를 붙이지 않는다 — "아니 A 말고 B" 정정이 나오면 B만 답한다.
- 시세·비용 수치는 실매물 집계 기준으로 근거를 밝히고, 보유기간 후 처분가 같은 추정값은 '추정' 명시.
- 매물 링크를 받으면 성능·상태점검기록부 + 카히스토리 기준으로 같이 본다고 다음 단계를 제안한다.
- 장기렌트·리스 승계 매물은 목록 단계에서 제외한다 — 승계는 인수 조건·보증·잔존 리스크가 일반 매매와 달라 가격 비교 대상이 아니다.
- 최종 추천 전에 상위 후보의 판매자 문구·보험이력 금액(내차피해/타차가해 총액·횟수)·진단 코멘트를 뜯어 재랭킹한다 — 가격+구조적 플래그만으로 뽑은 1순위는 이력 확인 후 뒤집히는 게 일상이다.
- 후보를 배지(트림명) 문자열로만 비교하지 않는다 — 같은 배지가 2인승 화물밴이나 렌트 전용 트림으로도 등록된다. 저가 띠를 만나면 승차정원(`spec.seatCount`)부터 확인한다.
- 신차가 대비 잔존율 70%+ 구간(보통 3년 미만 연식) 매물은 진입가가 싸 보여도 급감가 구간 위에 있다 — 3년 보유면 감가가 월 20만+로 최대 항목이 된다. "가성비 좋다"는 판정은 연식 상한을 함께 말해야 완성된다.
- **보증기간을 정비비 면제로 계산하지 않는다.** 제조사 보증은 제조결함(고장)만 덮고 소모품(타이어·패드·엔진오일·LPG 연료필터·냉각수·배터리)은 구간 안에서도 전액 유상이다. 게다가 커버 구간은 앞 3~5년/6~10만km에 몰려 있어 정비 위험이 가장 낮은 구간과 겹친다 — 10년 보유에서 보증이 면제해주는 금액은 월 0.3만 수준이다. 항목별 기간은 제조사 공식 보증표에서 확인한다(암기·추정 금지). 상세는 `references/data-pipeline.md`.
- 7년 이상 장기 보유로 판단할 때는 매입가 차액과 정비 누적 차액을 같은 표에 나란히 놓는다 — 저가 고km 매물은 감가가 작아도 정비에서 역전되므로, 감가만 비교하면 순위가 뒤집힌다.

## Procedure

### 1. 조건 고정

```text
예산: 총예산과 차값 구분 (이전비·보험·초기 소모품 별도)
보유기간·폐차 여부: 몇 년 타다 파는지 / 폐차까지
용도: 출퇴근 km, 고속 비중, 실장 여부
필수 옵션: 카플레이, 후방카메라, 열선 등
보험 상황: 첫차 여부 (보험료가 예산을 잠식함)
```

사용자가 이미 말한 조건을 재질문하지 않는다. 빠진 것은 합리적 기본값 + 가정 명시로 진행한다.

### 2. 커뮤니티 정설 수집 (DCInside 중고차 마이너 갤)

- 갤 내부 검색 URL: `https://gall.dcinside.com/mgallery/board/lists/?id=used_car&s_type=search_subject_memo&s_keyword=<URL-인코딩>`
- 브라우저로 열어 `a[href*="board/view"]`에서 글번호·제목 수집 후 관련 글만 연다.
- 댓글은 데스크톱 페이지에서 iframe으로 로드되어 빈 값이 된다 → `https://m.dcinside.com/board/used_car/<글번호>`를 연다. 셀렉터는 개편을 탄다(`.comment_item`·`.cmt_item`은 빈 배열을 돌려준다) — 클래스가 `/cmt|comment/`에 매칭되고 자식 요소가 4개 미만인 li·div의 innerText를 모아 읽는 방식이 개편에 강하다.
- 질문글은 갤 템플릿(우선성/가격대/필수옵션/주행환경/기타)을 따른다. **여러 스레드에서 반복되는 댓글 답변이 정설**이고, 단일 글 의견은 후순위다.
- 갤 공지·사례 모음글(매니저 작성)은 플랫폼 신뢰도 판정의 1차 근거로 쓴다.
- 시세는 웹검색으로 연식별 실매물 평균·범위를 확보한다. 키워드: `<모델> 중고 시세 연식별 평균`.
- Pitfall: 갤 검색 키워드는 타 갤러리 게시물까지 섞여 온다 — 갤러리명 '중고차'인 것만 골라 연다.

### 2.5 실매물 직접 조회 (엔카 search API)

- 정설로 방향을 잡았으면 옵션 조건·가격 밴드는 엔카 search API 실측으로 확정한다 — 호출 문법, HTTP 코드 의미(404=필드 키 오류 / 400=파서 오류 / 200+Count:0=정상 0건), 옵션 토큰 캡처 절차, 공유 링크 생성은 `references/encar-search-api.md`.
- 옵션 하드 조건("ACC는 무조건" 등)은 정설 인용으로 끝내지 말고 실매물 카운트와 가격 밴드로 검증해 제시한다.
- 리스트 아이템에는 승차정원·신차 기준가가 없다 — `GET /v1/readside/vehicle/{id}`(같은 헤더)로 `spec.seatCount`(2=화물밴), `category.originPrice`(신차가), `contact.userType`, `manage.viewCount`를 붙여 저가 띠의 정체와 잔존율을 확정한다. 필드 목록은 `references/encar-search-api.md`.

### 3. 월비용 모델링 (execute_code)

- 구성: 감가/월 + 보험/월 + 자동차세/월 + 정비/월 + 연료/월.
- 감가/월 = (구매가 − 보유기간 후 처분가) / 보유개월. 처분가는 (트림 × 연식) 중위가 표에서 `(연식 − 보유년수)` 행을 잡고 매물 주행거리 차이를 만km당 계수로 보정해 추정한다.
- 처분가에서 매도 마진 5%(경매·매매상 수수료)를 빼고, 자동차세는 차령 3년차부터 연 5% 경감을 반영한다 — 계수·단가·보험 앵커·검산 비중은 `references/budget-vehicle-map.md`.
- 정비비는 km 구간 단가에 **연차별 곡선**을 씌워 넣는다: 보증 구간 60~65만/년 → 보증 종료 직후 140만/년으로 점프 → 20만km+ 200만/년. 고장(보증 대상) 기대값은 10년 100만 내외로 소모품과 분리해 적는다.
- 보유기간이 5년을 넘으면 3년/5년/10년 월합계를 한 표에 병기한다 — 기간이 늘수록 감가 비중이 줄고 정비·연료 누적이 지배해 순위가 바뀐다.
- 기준값 근거와 산출 표를 답변에 그대로 보여준다.
- 판정 규칙은 `references/budget-vehicle-map.md` 참조: "덜 떨어진다 ≠ 싸다", 단기 보유는 감가가 지배, 보유기간을 늘려도 티어 간 순위가 뒤집히는지 확인.

### 4. 차종·트림 추천

- 예산→후보 매핑, 보유기간별 월비용, 카플레이 지원 조건, 트림 판정은 `references/budget-vehicle-map.md`.
- 수치는 조사 시점 기준이므로 재사용 시 Step 2로 갱신한다.
- '몇 년 타다 파는' 차에 상위 트림 차액은 감가로 증발한다 — 트림 추천은 옵션 체감 차이와 시세 차액으로 판정한다.

### 4.5 API 파이프라인

- 엔카 검색/상세 API, ACC 토큰(`Options.크루즈 컨트롤(어댑티브)`), 리스크 플래그 자동화, 헤이딜러 DOM 수집, 카히스토리·성능기록부 판독 기준은 `references/data-pipeline.md`.

### 4.6 후보 심층 확인·재랭킹

- 1차 랭킹(SQLite ORDER BY cost_month)은 방향 잡기용이다. 상위 5~7개는 매물별로 ① 장기렌트/리스 승계 여부(SellType) ② 보험이력 금액(내차피해·타차가해) ③ 엔카진단 코멘트의 골격 키워드 ④ 판매자 문구를 확인해 재랭킹하고, 비교표에 이 근거를 그대로 실는다.
- 동일 차량이 다른 ID로 재등록된 쌍은 하나로 묶어 판단한다.
- 방법(엔드포인트·스크레이프 패턴)은 `references/data-pipeline.md`.

### 5. 매물 검증 루틴

1) 성능·상태점검기록부(법정양식, 잘려 있으면 제외)
2) 카히스토리: 보험이력 1건당 내차피해 200만 이상은 거름, 렌트·영업용 이력 거름
3) 자동차365: 압류·저당·소유 이력
4) 카바조(정비소 리프트 동행 점검) — 커뮤니티 표준 답
5) 시운전: 변속 충격·직진 쏠림·전 버튼 작동

매매업자 매물은 '제시' 등록 여부를 확인한다.

## Platform Facts (2026-09 조사 기준)

- 준중형 BSD 저가 실측(ACC 불요 시): AD 밸류플러스 2017~18 550~600(12~15만km), K3 프레스티지 620~690. 다만 이 밴드는 사고·렌트 출신 비율이 높다 — 저가 최저 매물은 성능기록부 사고 True 다수. 이력 깨끗한 후보는 최저가보다 30~70 높은 매물에서 나온다.
- BSD(후측방 경보) 필터 토큰: `Options.후측방 경보 시스템` — 국산 BSD 매물 6만+. ACC 없이 후측방만 원하면 이 토큰으로 2016~2023 전 차급 검색 가능. AD 밸류플러스는 BSD 있음(ACC/크루즈 없음) — ACC 필수가 아니면 가격 밴드가 크게 내려간다.
- BSD-only 저가 실측(36개월): 올 뉴 모닝 2017 디럭스 600(5.5만km) 30만/월이 최저 — 감가 2.4에 보험·유류·정비 모두 최저. 레이 ACC 매물(36.3)보다 6만/월 저렴하나 열선·스마트키 없음.
- 경차/소형 ACC 실측: 레이는 FL(2022~)만 ACC(시그니처 1,190~1,320, 렌트승계 주의, '밴' 혼입 배제). 모닝 JA 시그니처/프레스티지 ACC(2021 프레스티지 1,080/5.5만km ~ 2024 시그니처 1,150/1.9만km). 경차는 감가 동급이어도 보험+세+유류 월 -9~10만. 근시 정비(1년) 추정: 노후 경차 ~90만, 저km 준신차 ~15만.
- 수입차 TCO 실측(어코드 1.5T 2019 1,250~1,350): 감가는 국산 대비 비슷하나 보험(+5)+정비(+3.5~5)+유류(+6)로 월 +18 → 3년 +620만. 감가만 보고 판단 금지.
- 리스크 API 404 매물은 상세페이지 '차량이력' 섹션에서 내차 피해/타차 가해 총액+건수를 직접 파싱한다.
- 엔카믿고/홈서비스: 반품 시 탁송비+재상품화비+이용료가 고객 부담 — 하루 만에 반품해도 수십만 원 손해 사례 다수(갤 공지 사례 모음). '진단++'라도 점검 범위가 소비자 기대와 다르다.
- 케이카: 무난 후기와 불만 후기 혼재. 대안으로 가장 많이 언급되는 수준.
- 커뮤니티 정설: "플랫폼 믿고 한 곳만 보지 말 것", "카바조 보내라". 팔 때는 헤이딜러/카머스/엔카 경매 비교.
- 택부(택시부활차): 개인택시 출신만. 법인택시·경비부활·단기렌트 출신은 배제. 인수 후 예방정비(오일·미션오일·연료필터 등) 예산 별도 확보.
- 노후 LPG 중형(LF 가스 500~600대): 연료비는 싸지만 정비비 리스크 + 트렁크 1/4~1/3 손해.
- QM6 2.0 LPe(더 뉴 QM6, `LPG(일반인 구입)`) 5인승 실측(2026-09): 2023+ LPG 91건 중 5인승 74 / **2인승 화물밴 17** — '퀘스트 …LE' 배지가 곧 2인승이고 1,230~1,790만 저가 띠의 정체다. 5인승 중위가 2023 LE 1,840 / RE 1,960 / 2024 RE 2,250 / 2026식 신차급 2,780, 신차 기준가 LE 2,749~2,931·RE 3,095~3,220 → 3.5년차 잔존 LE 66~72%·RE 58~62%. 36개월 TCO 1위는 2023 LE 4.5만km·1,830만(월 51.6)이고 같은 급 가솔린 GDe(2,200)는 월 66.0 — LPG 우위 월 9.9만. LPe 고질병은 연료펌프·LPG 압력센서(16만km+ 시동 꺼짐)이고 냉간 시동·가스냄새·연료게이지 오차는 LPG 전반 점검 항목. ACC(어댑티브)는 LPG 670건 중 161건이고 배지가 RE 시그니처 77 · RE 39 · 프리미에르 33 · LE 시그니처 10 · LE 2 — **2.0 LPe LE 기본형에는 ACC가 없다**. ACC 하드 조건이면 LE 저가 후보를 1순위에 두지 말고 RE/프리미에르 밴드에서 보험 이력 클린을 찾는다.

## Answer Format

- 결론 먼저 → 근거(커뮤니티 반응 인용은 한 줄씩) → 계산표(있으면) → 주의점 → 다음 단계(매물 링크 요청).
- 차종 비교는 등수를 붙여 나열하고, 계산은 표로.
- 보유기간 가정이 바뀌면 3년/5년/10년 월합계를 병기해 순위 변동을 보여준다.
- 앞선 답변에서 올렸던 후보를 내리거나 순위를 뒤집었으면 그 사실과 사유(보험이력 수치 등)를 명시한다 — 조용히 목록에서 빼면 사용자가 이전 답변을 검증할 수 없다.

## Common Pitfalls

1. 데스크톱 DC에서 댓글을 iframe으로 읽으려다 빈 값을 받는다 — mobile 버전으로 읽는다.
2. 갤 검색 결과에 타 갤러리 글이 섞인다 — 갤러리명 확인 후 연다.
3. 매물가를 실거래가로 쓴다 — 실거래가는 매물가보다 낮다.
4. 시세 기준이 다른 사이트(실거래가 vs 등록매물가 vs 딜러입찰가)를 섞어 비교한다.
5. 처분가를 연식별 실매물 기울기 없이 감으로 잡는다 — execute_code로 계산한다.
6. 첫차 보험료를 과소평가해 예산 전액이 차값으로 간다 — 초기 비용 별도 확보를 권한다.
7. 제휴마케팅 블로그의 추천을 커뮤니티 정설처럼 인용한다.
8. 플랫폼 광고 문구(보증·환불)와 실비용 구조(탁송·재상품화 고객 부담)를 분리하지 않는다.
9. 엔카 옵션 필터 토큰을 추측으로 만든다 — 모바일 UI에서 캡처해 API Count로 검증한다. 404=키 오류, 400=문법 오류, 200+Count:0=정상 0건.
10. PriceAsc 결과의 낚시가격(1~50만)과 ID만 다른 중복 등록을 그대로 집계한다 — 현실가 하한 필터 + (가격·연식·주행거리) 중복 제거 후 센다.
11. 배지 문자열만으로 트림·차급을 분류한다 — 같은 배지가 2인승 화물밴(seatCount 2)이거나 렌트 전용 트림일 수 있다. 통계 전에 승차정원을 붙여 걸러낸다.
12. 급감가 구간(3년 미만·잔존 70%+) 매물을 '가성비'로 추천한다 — 감가가 최대 항목이 되는 구간이므로 연식 상한과 함께 판정한다.
13. 처분가에서 매도 마진과 자동차세 경감을 빼먹는다 — 감가가 과소, 세금이 과대 계산되어 순위가 뒤집힌다.
14. 보증기간을 '정비비 0'으로 잡는다 — 보증은 고장만 덮고 소모품은 유상이며, 커버 구간(앞 3~5년/6~10만km)이 정비 위험 최저 구간이라 실효 면제액이 작다. 장기 보유 정비를 크게 과소평가하게 된다.
15. 성능기록부의 `accdient=False`를 '보험 이력 없음'으로 읽는다 — 그 플래그는 골격 사고만 본다. 내차피해 총액·건수와 타차가해는 record/open으로 따로 읽어야 하고, 무사고 표기 + 내차피해 4건/588만 + 타차가해 4건/570만 같은 조합이 실제로 나온다.
16. 재등록 쌍 매물에서 한 ID의 기록부가 404면 '데이터 없음'으로 결론낸다 — 형제 ID(가격·연식·km·배지 동일)에 200이 살아 있는 경우가 흔하다. vin을 얻은 쪽으로 record/open을 부른다.

## Verification Checklist

- [ ] 조건 재질문 없이 진행했다.
- [ ] DCInside 실제 글·댓글 근거(여러 스레드 반복 답변)를 확보했다.
- [ ] 계산은 execute_code 표로 보여줬고 추정치에 표시했다.
- [ ] '덜 떨어진다 ≠ 싸다' 관점으로 인기 프리미엄을 걸렀다.
- [ ] 트림·옵션(순정내비/카플레이) 확인 포인트를 전달했다.
- [ ] 옵션 하드 조건(예: ACC)을 실매물 카운트·가격 밴드로 검증해 전달했다.
- [ ] 승계매물(렌트·리스)을 제외했고, 최종 후보의 보험이력 금액·진단 코멘트·판매자 문구 확인 후 재랭킹했다.
- [ ] 정비비를 보증기간으로 0 처리하지 않았고, 장기 보유면 매입가 차액과 정비 누적 차액을 같은 표에 놓았다.
- [ ] 성능기록부 무사고 플래그와 record/open 보험 이력을 별개로 확인했다.
