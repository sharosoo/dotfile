# Korea Shopping Price and Stock

## Overview

한국에서 실제 주문할 수 있는 **동일 제품·동일 옵션**의 총비용과 품절 여부를 확인한다. 검색 결과의 표시가를 복사하지 않고 상세 페이지에서 SKU, 옵션, 판매자, 배송비, 구매 버튼 상태를 다시 검증한다.

가격과 재고는 빠르게 바뀌므로 모든 결과에 확인 시각과 신뢰도를 붙인다. 카드·멤버십·신규회원처럼 재현할 수 없는 할인은 누구나 결제 가능한 가격과 분리한다.

## When to Use

- 한국에서 살 수 있는 곳 중 최저가를 찾을 때
- 쿠팡, 네이버쇼핑, 11번가, G마켓, 공식몰 등을 비교할 때
- 특정 색상·용량·사이즈의 품절 여부를 확인할 때
- 국내 정발과 해외직구의 실구매 비용·배송·AS를 비교할 때

후기 조사가 주목적이면 `product-review-research`를 사용한다. 가격·재고를 계속 감시하려면 `personal-watchlist` 방식의 cron을 사용한다.

## 기본 원칙

1. **동일 SKU만 직접 비교:** 세대, 용량, 구성, 상품 상태가 다르면 별도 행으로 둔다.
2. **검색 결과는 후보일 뿐:** 가격과 재고는 상세 페이지에서 확인한다.
3. **옵션 단위 판정:** 페이지가 살아 있어도 원하는 옵션은 품절일 수 있다.
4. **조건부 할인 분리:** 카드, 멤버십, 앱, 첫 구매 가격은 기본 총비용이 아니다.
5. **확인 시각 기록:** 가격과 재고에는 KST 기준 시각을 붙인다.

## 1. 구매 조건과 SKU를 고정한다

```text
배송지: 대한민국(기본값, 도서산간 제외)
정확한 제품명/모델 번호/세대:
원하는 색상·용량·크기·사이즈:
필수 구성품:
상품 상태: 새제품 기본, 리퍼·중고 허용 여부
국내 정발만 또는 해외직구 포함:
결제 조건: 누구나 가능한 결제 기본
배송 기한:
```

사용자가 이미 말한 조건은 다시 묻지 않는다. 결과를 크게 바꾸는 정보가 빠졌으면 합리적인 기본값을 쓰고 가정을 밝힌다.

다음은 같은 상품으로 합치지 않는다.

- 본체 단품과 번들
- 국내 정식 유통과 병행수입
- 새제품과 반품·전시·리퍼·중고
- 용량·크기·세대가 다른 변형
- 기능, 전압, 보증이 다른 해외판

**완료 기준:** 비교 SKU와 허용 가능한 대체 SKU가 구분되어 있다.

## 2. 판매처 후보를 넓게 찾는다

제품군에 따라 다음을 조합한다.

- 제조사 한국 공식몰과 공식 인증 판매점
- 네이버쇼핑, 다나와, 에누리 등 가격비교 서비스
- 쿠팡, 11번가, G마켓, 옥션, SSG, 롯데ON 등 종합몰
- 제품군 전문몰
- 허용된 경우 한국 직배송이 가능한 해외 판매처

검색어 예시:

- `"모델 번호" 가격`
- `"모델 번호" 색상 용량 구매`
- `"정확한 제품명" 공식몰`
- `"모델 번호" site:shopping.naver.com`
- `"모델 번호" site:coupang.com`
- `"모델 번호" 재고 OR 품절`

가격비교 서비스의 상품 묶음에는 다른 SKU가 섞일 수 있으므로 개별 판매 페이지에서 재확인한다.

**권장 범위:** 공식몰 1곳과 독립 판매처 3곳 이상을 시도한다. 판매처가 적거나 접근이 막히면 실제 확보 범위를 밝힌다.

## 3. 상세 페이지에서 실구매가를 검증한다

후보마다 다음을 기록한다.

```text
판매처/판매자, 상세 URL
정확한 SKU·옵션, 새제품/리퍼/중고
상품가, 공개 즉시 할인, 배송비
필수 옵션·설치비·확정 가능한 관부가세
누구나 결제 가능한 기본 총비용
조건부 최저가와 조건
적립 예정액(별도)
국내 정발/병행수입/해외직구
공식 판매 여부, 반품·보증·AS
예상 배송일, 확인 시각(KST)
```

### 기본 총비용

```text
상품가
- 로그인 없이 누구나 즉시 적용되는 할인
+ 필수 배송비
+ 필수 설치비·옵션비
+ 결제 전에 확정 가능한 세금·관부가세
```

다음은 기본 총비용에서 빼지 않는다.

- 특정 카드 청구 할인
- 유료 멤버십 가격
- 앱·신규회원·첫 구매 쿠폰
- 보유 포인트와 적립금
- 리뷰 작성 후 포인트
- 추후 적립 예정액
- 다른 상품 구매를 요구하는 할인

해외직구 관부가세가 예상치뿐이면 확정 총비용처럼 쓰지 않는다. 환율을 사용하면 기준과 시각을 적는다.

**완료 기준:** 각 비교 행에 기본 총비용 또는 계산 불가 이유가 있다.

## 4. 옵션 단위 재고를 판정한다

| 상태 | 판정 기준 |
|---|---|
| 재고 있음 | 원하는 옵션 선택 가능 + 구매/장바구니 활성 + 한국 배송 가능 |
| 소량 | 판매 페이지가 잔여 수량이나 마감 임박을 명시 |
| 예약판매 | 주문 가능하지만 발송 시작일이 미래 |
| 주문 후 입고 | 결제 가능하나 조달 기간이 표시됨 |
| 품절 | 원하는 옵션에 품절 표시 또는 구매 버튼 비활성 |
| 판매 종료 | 단종·판매 종료·상품 없음이 명시됨 |
| 확인 불가 | 로그인, CAPTCHA, 지역 선택, 동적 UI, 차단으로 검증 실패 |

### 강한 재고 증거

- 원하는 옵션을 실제 선택할 수 있음
- 구매 또는 장바구니 버튼이 활성화됨
- 한국 배송과 예상 배송일이 표시됨
- `재고 있음`, `N개 남음`이 명시됨

### 약한 증거

- 검색 결과에 가격만 노출됨
- 과거 상품 페이지 제목이 남아 있음
- 옵션을 고르지 못했는데 빠른 배송 배지만 보임
- 가격비교 사이트의 가격 기록만 존재함

약한 증거만 있으면 재고 있음으로 확정하지 않는다.

정적 추출로 옵션과 버튼이 안 보이면 브라우저를 사용한다. 옵션 선택과 장바구니 버튼 확인까지만 하고, **주문 제출이나 결제 단계로 진행하지 않는다.** 로그인·CAPTCHA·주소 입력이 필요하면 우회하지 않는다.

**완료 기준:** 원하는 옵션별 재고 상태와 근거 문구가 기록되어 있다.

## 5. 한국에서 구매 가능한지 확인한다

### 국내 판매

- 대한민국 배송지 선택 가능 여부
- 국내 반품 주소와 판매자 정보
- 정식 수입·병행수입 여부
- 중요한 품목의 KC 인증, 전압, 플러그
- 제조사 국내 AS 대상 여부

### 해외직구

- 대한민국 직배송 가능 여부
- 배송대행지 필요 여부
- 국제배송비와 예상 관부가세
- 배터리·식품·화장품 등 반입 제한 가능성
- 110/220V, 50/60Hz, 플러그, 지역 제한
- 반품 국제배송비와 국내 AS 제외 여부

한국어 페이지라고 한국 배송이 가능한 것은 아니다. 배송대행지가 필요하면 `한국 직배송`으로 쓰지 않고 별도 후보로 둔다.

## 6. 판매자 위험과 사후비용을 본다

- 공식 판매자 또는 플랫폼 인증 여부
- 판매자 평점과 최근 거래
- 지나치게 낮은 가격, 모델명 불일치, 옵션 미끼 가격
- 정품·병행수입·벌크·OEM 표기의 명확성
- 반품 기간과 개봉 후 조건
- 제조사 보증과 판매자 자체 보증
- 필수 소모품, 필터, 구독, 설치비

신뢰가 불명확하면 `위험·주의` 열에 적되 근거 없이 사기라고 단정하지 않는다.

## 7. 정렬과 추천

표는 `누구나 결제 가능한 기본 총비용` 오름차순으로 정렬한다. 조건부 가격은 별도 열에 둔다.

- **최저 실구매가:** SKU·재고·총비용 검증이 끝난 최저가
- **안심 구매:** 공식 유통, 국내 AS, 반품 조건이 좋은 후보
- **빠른 수령:** 배송일이 구체적이고 재고 신뢰도가 높은 후보

가격 차이가 작으면 무조건 최저가를 택하지 말고 AS·반품·배송 차이를 설명한다.

## 8. 최종 답변 형식

```markdown
# 결론
- 최저 실구매가:
- 안심 구매:
- 빠른 수령:
- 확인 시각: YYYY-MM-DD HH:MM KST

## 동일 SKU 가격·재고 비교
| 판매처 | 판매자 | 옵션 | 기본 총비용 | 조건부 가격·조건 | 재고 | 배송 | 유통/AS | 위험·주의 | 근거 |

## 제외하거나 별도로 본 상품
| 상품 | 제외 이유 |

## 가격 계산 메모
- 배송비, 쿠폰, 카드, 멤버십, 관부가세 처리

## 재고 판정 근거
- 판매처별 옵션 선택과 구매 버튼 상태

## 확인하지 못한 점
- 로그인, CAPTCHA, 지역 선택, 변동 가능성
```

각 행에는 검색 결과가 아닌 상세 상품 URL을 넣는다.

## Common Pitfalls

1. 액세서리나 작은 옵션의 미끼 가격을 본체 가격으로 쓴다.
2. 용량·세대·번들·리퍼 여부가 다른 상품을 섞는다.
3. 배송비와 필수 설치비를 누락한다.
4. 카드·멤버십 가격을 누구나 가능한 가격으로 쓴다.
5. 적립 예정액을 즉시 할인으로 계산한다.
6. 검색 노출을 재고 있음으로 판단한다.
7. 페이지 전체는 살아 있지만 원하는 옵션이 품절임을 놓친다.
8. 해외직구 환율·관부가세를 확정값처럼 쓴다.
9. 정발과 병행수입의 AS를 동일시한다.
10. 확인 시각을 누락한다.
11. 로그인·CAPTCHA를 우회하거나 주문을 진행한다.

## Verification Checklist

- [ ] 동일 모델·세대·옵션·구성·상태만 직접 비교했다.
- [ ] 공식몰과 독립 판매처를 시도하고 범위를 밝혔다.
- [ ] 상세 상품 URL을 제시했다.
- [ ] 기본 총비용과 조건부 가격을 분리했다.
- [ ] 배송비, 필수 비용, 확인 가능한 세금을 반영했다.
- [ ] 원하는 옵션 선택과 구매 버튼을 확인했다.
- [ ] 정발·병행수입·해외직구와 AS를 구분했다.
- [ ] 품절·예약·주문 후 입고·확인 불가를 구분했다.
- [ ] 확인 시각을 KST로 표시했다.
- [ ] 접근 차단과 계산 불확실성을 밝혔다.
- [ ] 주문·결제·로그인 우회를 하지 않았다.
